# About
## Installation

Install via the NuGet Package Manager

## 🎯 Design Goals

- Unified base level BLL functionality like standardized Get All requests and model services and repository handling
- Enable easy unit and integration testing
- Model and model parameters should be real world consistent

## 🧪 Testing

- Extensions should be easily testable in isolation
- Unexpected data should be handled properly with clear failure or error
- No external dependencies
